# 🚀 Способы запуска Canvia

## 📋 Доступные методы

1. **Автоматический запуск** (рекомендуется)
2. **Скрипт в фоне**
3. **Ручной запуск в терминале**
4. **Режим разработки с hot-reload**
5. **Перезапуск**
6. **Остановка**

---

## 1. ⚡ Автоматический запуск (Windows)

### Самый простой способ

Дважды кликните на **`start.bat`** в корне проекта.

Откроются два окна:
- **PROFI Server** - серверная часть (порт 5000)
- **PROFI Frontend** - веб-интерфейс (порт 8080)

Приложение автоматически откроется в браузере на **http://localhost:8080**

### Что происходит внутри

```bash
# Сервер
cd server
npm install (если нужно)
npm run build
npm start

# Фронтенд (в отдельном окне)
npm install (если нужно)
npm run build
npm preview
```

---

## 2. 🖥️ Запуск в фоне (без видимых окон)

### Windows

Дважды кликните на **`start-hidden.bat`**

Окна консоли не будут видны, сервер запустится в фоне.

**Остановка:** `stop.bat` или `taskkill /F /IM node.exe`

### PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File start-hidden.ps1
```

### VBScript (совсем без окон)

```cmd
cscript start-hidden.vbs
```

---

## 3. 🔧 Ручной запуск (классический способ)

Используйте этот способ если скрипты не работают.

### Шаг 1: Установка зависимостей (первый раз)

**Терминал 1:**
```bash
# Перейти в папку сервера
cd server

# Установить зависимости
npm install

# Скомпилировать TypeScript
npm run build
```

**Терминал 2:**
```bash
# Установить зависимости фронтенда
npm install
```

### Шаг 2: Запуск сервера (Терминал 1)

```bash
cd server
npm start
```

Вы должны увидеть:
```
✅ PROFI Server listening on http://localhost:5000
📦 Database: /path/to/profi-planner.db
```

### Шаг 3: Запуск фронтенда (Терминал 2)

```bash
npm run build
npm run preview
```

Вы должны увидеть:
```
  ➜  Local:   http://localhost:8080/
```

### Шаг 4: Открыть браузер

```
http://localhost:8080
```

---

## 4. 🔥 Режим разработки (с hot-reload)

Этот способ для разработчиков - код перезагружается при сохранении файлов.

### Шаг 1: Сервер в режиме разработки

**Терминал 1:**
```bash
cd server
npm run dev
```

Вы увидите:
```
✅ PROFI Server running in DEVELOPMENT mode
⚡ Hot reload enabled
```

### Шаг 2: Фронтенд в режиме разработки

**Терминал 2:**
```bash
npm run dev
```

Вы увидите:
```
  ➜  Local:   http://localhost:5173/
  ➜  press h + enter to show help
```

### Шаг 3: Открыть браузер

```
http://localhost:5173
```

Когда вы измените код, приложение перезагрузится автоматически.

---

## 5. 🔄 Перезапуск

### Быстрый перезапуск обоих сервов

```bash
restart.bat
```

### Или вручную

1. Закройте оба окна консоли (Ctrl+C)
2. Запустите `start.bat` снова

---

## 6. 🛑 Остановка

### Способ 1: Скрипт (рекомендуется)

```bash
stop.bat
```

### Способ 2: Закрыть окна

Закройте оба окна консоли вручную.

### Способ 3: Из PowerShell

```powershell
taskkill /F /IM node.exe
```

## 📝 Скрипты в деталях

### start.bat

```batch
@echo off
REM Проверка наличия node_modules и установка если нужно
REM Компиляция сервера
REM Запуск сервера и фронтенда в двух окнах
REM Автоматическое открытие браузера
```

### start-hidden.bat

Как start.bat, но без видимых окон консоли.

### start-dev.bat

Запускает в режиме разработки с hot-reload.

### restart.bat

Останавливает оба процесса и запускает снова.

### status.ps1

Проверяет статус сервера и выводит логи.

---

## 🔄 Процесс инициализации при запуске

1. **Проверка зависимостей**
   - Если нет `node_modules`, запускается `npm install`

2. **Компиляция TypeScript** (сервер)
   - Сервер компилируется из `server/src/` в `server/dist/`

3. **Инициализация БД**
   - Если нет файла `server/data/profi-planner.db`, создаётся новая
   - Таблицы инициализируются автоматически

4. **Запуск сервера**
   - Сервер слушает на порту 5000
   - Выполняет миграции если нужны

5. **Запуск фронтенда**
   - Строится React приложение
   - Запускается на порту 8080
   - Открывается браузер

## ⚙️ Переменные окружения

### Сервер (.env)

```env
PORT=5000
NODE_ENV=production
DATABASE_PATH=./data/profi-planner.db
JWT_SECRET=your-secret-key
CORS_ORIGIN=http://localhost:8080,http://192.168.2.104:8080
```

### Фронтенд (.env.local)

```env
VITE_API_URL=http://localhost:5000/api
```

Если нужно использовать другой сервер, отредактируйте эти переменные.

## 🔍 Проверка работы

После запуска проверьте:

**Сервер работает:**
```bash
curl http://localhost:5000/api/health
```

Должен ответить:
```json
{"status": "ok"}
```

**Фронтенд работает:**
```
http://localhost:8080
```

Должна открыться страница логина.

## 🌐 Доступ извне (Cloudflare Quick Tunnel)

Чтобы дать ссылку монтажнику без настройки сети:

```bash
cloudflared tunnel --url http://localhost:8080
```

Выданный `https://xxx.trycloudflare.com` открываете ему — логин и API идут
через тот же туннель. Уже настроено:

- `vite.config.ts`: `allowedHosts: ['.trycloudflare.com']` (поддомен каждый раз новый — wildcard покрывает), `proxy /api → localhost:5000`
- `src/api.ts`: вне локалки фронт ходит в относительный `/api` (порт 5000 снаружи закрыт)
- `server.ts` CORS: разрешён `*.trycloudflare.com`

Второй туннель для `:5000` не нужен.

## 💡 Советы

- **Первый запуск медленный** - это нормально, устанавливаются зависимости
- **Для развития** используйте `start-dev.bat` с hot-reload
- **Для production** используйте `start.bat` с собранными файлами
- **В фоне** используйте `start-hidden.bat` чтобы не видеть окна
- **Перезапуск** через `restart.bat` быстрее чем stop + start
