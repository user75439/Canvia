# Автосоздание бригад через Drag & Drop

## ✅ Фаза 1: Базовая механика - ГОТОВО!

### Реализовано

#### Frontend (src/App.tsx)

**1. Функция поиска близких плиток:**
```typescript
findNearbyTile(x, y, radius=100px, types=['installer', 'brigade'])
```
- Ищет плитки монтажников и бригад в радиусе 100px от точки
- Исключает перетаскиваемую плитку
- Возвращает ближайшую подходящую плитку

**2. Обработка слияния при Drop:**
```typescript
handleMouseUp()
  → if (draggedTile.type === 'installer')
    → nearby = findNearbyTile(100px)
    → if (nearby.type === 'installer')
        → handleMergeTwoInstallers()
    → if (nearby.type === 'brigade')
        → handleAddInstallerToBrigade()
```

**3. Слияние двух монтажников:**
```typescript
handleMergeTwoInstallers(id1, id2, x, y)
  1. Получает данные монтажников
  2. Вызывает brigadeAPI.findOrCreate([id1, id2])
  3. Удаляет обе плитки монтажников
  4. Создает плитку бригады на месте второго
```

**4. Добавление в существующую бригаду:**
```typescript
handleAddInstallerToBrigade(brigadeId, installerId)
  1. Получает данные монтажника
  2. Вызывает brigadeAPI.addMember(brigadeId, installerId)
  3. Удаляет плитку монтажника
  4. Перезагружает данные
```

**5. Визуальная подсветка:**
- При перетаскивании монтажника обновляется `nearbyTile`
- Близкая плитка подсвечивается зеленым кольцом с пульсацией:
  ```css
  ring-4 ring-green-500 animate-pulse
  ```

#### Backend (server/src/routes/brigades.ts)

**1. POST /api/brigades/find-or-create**
```json
Request: { "installerIds": ["id1", "id2"] }
Response: { "brigadeId": "...", "isNew": true/false }
```

**Алгоритм:**
1. Сортирует IDs монтажников
2. Ищет бригаду с таким же составом:
   ```sql
   SELECT brigadeId 
   FROM brigade_members 
   GROUP BY brigadeId
   HAVING GROUP_CONCAT(installerId ORDER BY installerId) = 'sorted_ids'
   ```
3. Если нашел → возвращает существующую
4. Если нет → создает новую с snapshot данных

**2. POST /api/brigades/:id/members**
```json
Request: { "installerId": "..." }
Response: { "success": true }
```

**Алгоритм:**
1. Проверяет существование бригады и монтажника
2. Проверяет, не добавлен ли уже
3. Добавляет в brigade_members со snapshot:
   - installerId (для связи)
   - name (snapshot)
   - phone (snapshot)

#### API Client (src/api.ts)

```typescript
brigadeAPI.findOrCreate(installerIds: string[]): Promise<string>
brigadeAPI.addMember(brigadeId: string, installerId: string): Promise<void>
```

### Как работает

**Сценарий 1: Слияние двух монтажников**
```
1. Пользователь создает плитку "Иван"
2. Создает плитку "Петр"
3. Перетаскивает "Иван" на "Петр" (или близко, в радиусе 100px)
4. При приближении "Петр" подсвечивается зеленым
5. Отпускает кнопку мыши
6. Backend ищет бригаду [Иван, Петр]
7. Не находит → создает новую
8. Обе плитки удаляются
9. Появляется плитка бригады на месте "Петр"
```

**Сценарий 2: Добавление третьего монтажника**
```
1. Есть плитка бригады [Иван, Петр]
2. Создает плитку "Сергей"
3. Перетаскивает "Сергей" на бригаду
4. Бригада подсвечивается зеленым
5. Отпускает
6. Backend добавляет Сергея в бригаду
7. Плитка "Сергей" удаляется
8. Бригада обновляется → [Иван, Петр, Сергей]
```

**Сценарий 3: Переиспользование существующей бригады**
```
1. На вкладке "Сегодня" создали бригаду [Иван, Петр]
2. Переходим на вкладку "Завтра"
3. Перетаскиваем "Иван" на "Петр"
4. Backend находит существующую бригаду [Иван, Петр]
5. Переиспользует ее (не создает дубликат)
6. Создается плитка с той же brigadeId
```

### Технические детали

**Радиус слияния:** 100px от центра плитки
- Ширина плитки: 220px
- Высота плитки: ~160px
- Центр: (110, 80) относительно плитки

**Snapshot данных:**
При добавлении монтажника в бригаду сохраняется:
```sql
INSERT INTO brigade_members (
  id, brigadeId, installerId, 
  name, phone  -- snapshot!
)
```
Если монтажника удалят → его имя и телефон останутся в бригаде.

**Поиск дубликатов:**
```sql
GROUP_CONCAT(installerId ORDER BY installerId)
```
Сортировка гарантирует что [Иван, Петр] === [Петр, Иван]
