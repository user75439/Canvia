## 📝 Технические детали

### Алгоритм создания группы:
1. Пользователь выделяет несколько плиток (Shift + клик)
2. Нажимает кнопку "Создать группу"
3. Вводит название и выбирает цвет
4. Система автоматически рассчитывает:
   - `x = min(tile.x) - padding`
   - `y = min(tile.y) - padding`
   - `width = max(tile.x + tile_width) - min(tile.x) + 2*padding`
   - `height = max(tile.y + tile_height) - min(tile.y) + 2*padding`
5. Создается группа, плиткам присваивается `groupId`

### Алгоритм перемещения группы:
1. Пользователь тянет за заголовок/рамку группы
2. Вычисляется `deltaX` и `deltaY`
3. Обновляется позиция группы: `group.x += deltaX`, `group.y += deltaY`
4. Для каждой плитки с `groupId === group.id`:
   - `tile.x += deltaX`
   - `tile.y += deltaY`
5. Сохранение на сервер (оптимистичное обновление)

### Визуальная структура рамки:
```svg
<g> <!-- Группа -->
  <rect /> <!-- Фон рамки (полупрозрачный) -->
  <rect /> <!-- Граница рамки (цветная) -->
  <text /> <!-- Название группы сверху -->
  <!-- Плитки рендерятся отдельно -->
</g>
```

## 🎨 Дизайн
- Цвет по умолчанию: `#6366f1` (индиго)
- Доступные цвета: индиго, синий, зеленый, желтый, оранжевый, красный, розовый, фиолетовый
- Рамка: 2px solid, слегка скругленная (rx="8")
- Фон рамки: цвет группы с прозрачностью 0.05
- Название: жирный шрифт, 14px, сверху рамки с отступом
- Padding внутри группы: 20px от границ плиток

## ✨ Готовый функционал

### Создание группы:
1. Зажмите **Shift** и кликайте по плиткам для выделения
2. В header появится кнопка **"Создать группу (N)"**
3. Откроется модальное окно с выбором названия и цвета
4. Группа создается с автоматическим расчетом размеров

### Редактирование группы:
1. **Двойной клик** на заголовок группы
2. Откроется модальное окно редактирования
3. Можно изменить название и цвет

### Перемещение группы:
1. Тяните за заголовок группы (курсор изменится на "move")
2. Все плитки внутри группы двигаются вместе с ней
3. Изменения автоматически сохраняются

### Удаление группы:
1. Нажмите кнопку ❌ в правом верхнем углу заголовка
2. Группа удаляется без подтверждения
3. Плитки останутся на канвасе

### Добавление плиток в группу:
1. Зажмите **Shift** и выделите плитки, которые НЕ в группе
2. В header появится кнопка **"Добавить в группу (N)"**
3. Откроется модальное окно со списком групп
4. Выберите группу - плитки добавятся, границы пересчитаются

### Удаление плиток из группы:
1. Зажмите **Shift** и выделите плитки внутри ОДНОЙ группы
2. В header появится кнопка **"Убрать из группы (N)"**
3. Кликните - плитки выйдут из группы
4. Границы группы автоматически пересчитаются
5. Если группа осталась пустой - она удалится
